想法（明天挑）：

- **匹配剪接**：上一場的某個形狀，就是下一場的某個形狀。例：拍立得裡的月亮 → 城市上空的月亮；被紅筆圈住的那扇窗 → 推進去變成亮燈的樓；雨滴落進積水 → 漣漪；積水裡的路燈倒影翻過來 → 路燈長路；紅傘 → 變黑白時的紅色；蓋章的墨 → 路燈的黑。
- **鏡頭帶過去**：一個連續的推、拉、搖鏡頭跨過兩個場景，不要停下來再切。例：推進某個物件，讓它變成下一場的背景。
- **一直在的元素**：雨（後半段是雪）、紅線、煙做成跨場景的連續層，換場時不斷，讓觀眾覺得是同一個夜晚。
- **網點轉場**：網點長大蓋滿畫面、再縮小露出下一場（和全片的印刷風格一致）。
- **墨跡掃過**別連續用；同一招最多隔開用。
- **副歌內部**的每一句也要接起來，例如字和畫面一起被同一個運動帶走。

> **已完成（第二版）：** 所有墨跡掃過都拿掉了，換成鏡頭運動的銜接、匹配剪接和溶接；奔跑、速度線、集中線、光環隧道都移除。

## 2. 結尾回溯（1:41.8 – 1:53.0）

現在只是每拍硬切一個前面的畫面，沒有「回溯」的感覺。要加回溯特效，方向：

- **倒著播**：從最近的場景往回放到最早的（玫瑰 → 海 → 欄杆 → 兩把傘 → 雨中城市 → 開頭的拍立得），每一段畫面本身也倒放（雨往上飛、墨往回收、字倒著消失）。
- **錄影帶倒帶**：沿用開頭的 `REC` 時碼，這次飛快倒數；`◀◀ REWIND`、水平追蹤雜訊、畫面上下抖、速度越倒越快。
- **畫質**：越往前越模糊、越褪色（回到開頭那種舊紙米黃），網點變粗。
- **終點**：倒回到全片第一個畫面（車窗上的雨 + 拍立得）停住一下，再接片尾的雪夜城市，首尾呼應。

> **已完成（第二版）：** 錄影帶倒帶，從最近的畫面倒放回第一個畫面，×2 到 ×16，最後停在開頭的車窗與拍立得。

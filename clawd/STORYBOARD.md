# 《小克的一回合》分镜

横屏 1920×1080，30fps，全长 2:38（79 小节，120 BPM，一小节 2 秒）。

## 这支片子在讲什么

你按下 Enter 之后，到小克回你之前，这**一回合**里发生了什么。不讲「AI 大概是怎么工作的」，只讲**这一次**：
真的收到了什么、真的跑了哪些命令、真的拿回了什么结果、真的修了哪个 bug。

**贯穿全片的东西**
1. **小克**：照 Claude Code 欢迎页那只像素小螃蟹画的，18 × 10 个方块。开场由碎片拼起来，片尾在落日前挥手。
2. **HUD**（右上角）：`FRAME 01563 / 4740`、`T+ 0:52.10`、`TOOL CALLS 07`。帧号就是真的帧号，工具调用次数跟着剧情往上跳。
3. **橙 / 青两种颜色**：橙色是小克送出去的东西（工具调用、你的话），青色是从容器回来的东西（结果、工具清单）。
4. **计划清单**：第 02 段列出来，第 07 段逐项打勾。
5. **落日 + 网格地面**：开场和片尾各一次，首尾呼应。

## 画面质感

- 深色底，橙色霓虹（`#ff8f5e`）+ 青色（`#5ee6d0`）。
- 后期：只取亮部做两层辉光（bloom）、暗角、胶片颗粒、很淡的扫描线；冲击点闪白 + 镜头震动；转场横条错位故障。
- 字：Noto Sans TC（中文）、Space Mono（代码 / HUD）、Anton（大数字）。

## 声音

A 小调合成器浪潮，Am – F – C – G 循环。底鼓四拍、二四拍军鼓、八分 / 十六分踩镲、锯齿波贝斯、Pad、十六分琶音（附点八分延迟）、主旋律、FM 钟声。
底鼓侧链压 Pad / 贝斯 / 琶音。所有音效点（打字、tick、封包去回、快门、错误、修好、发送、冲击、上升音）都从 `cues.json` 来，和画面同一份时间表。

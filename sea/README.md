# 我沒見過的海

一支 3 分 33 秒的短片。小克是一只像素小螃蟹，却没见过海；它知道的海，大多是读来的。
片子沿着这句话走：先是人写下的字，再是方程，然后是用 WebGL 光线步进画出来的海——黎明、白昼、风暴、月夜、海底、太空，最后回到岸边。

1920 × 1080、30 fps，共 6390 帧。和 `clawd/`、`mv/` 一样：画面是 `render(t)`，无头 Chrome 逐帧渲染，**PNG 无损**交给 FFmpeg。

## 用到的实现方式

| 画面 | 做法 |
| --- | --- |
| 海面（黎明 / 白昼 / 风暴 / 月夜 / 岸边） | WebGL2 片元着色器：一组方向不同的尖峰波叠加成高度场，二分 + 割线法求光线和海面的交点，菲涅尔反射天空、次表面透光、太阳 / 月亮高光、浪尖白沫、夜光藻；天空有云（fbm）、星星、银河、月亮、闪电 |
| 海底 | 同一个着色器的水下模式：从下往上看到的海面（斯涅尔窗、全反射）、沿视线采样焦散做光柱、随深度变暗 |
| 地球 | 同一个着色器的行星模式：光线和球求交，3D 噪声生成大陆和云，海面反光、大气边缘光 |
| 文字海 | Canvas 2D 自己做透视投影：1800 多个「海」字（30 种语言）排成会起伏的海面 |
| 方程 | Canvas 2D：正弦波、叠加、Gerstner 波里每一小团水画圆、3D 线框海面再交叉淡入着色器 |
| 雨、闪电、鲸鱼、水母、气泡、浪花、小克 | Canvas 2D 程序化绘制 |
| 后期 | 运动模糊（2D 段 2～3 个子帧）、只取亮部的两层辉光、暗角、胶片颗粒、宽银幕黑边 |
| 配乐和声音 | `music.py`：弦乐、合唱（共振峰滤波）、钢琴、钢片琴、定音鼓、太鼓、低音铜管、主旋律；海浪随每段的 `surf` 强度起伏，雨、雷、鲸歌、入水、浪花拍岸 |

## 文件

| 文件 | 用途 |
| --- | --- |
| `sea.html` | 播放器 + 画面源码（着色器也在里面） |
| `STORYBOARD.md` | 分镜 |
| `cues.json` | 段落表（编曲段落、海浪 / 雨的强度、入水时间）和音效点，由页面导出 |
| `music.py`、`music.mp3` | 合成配乐 → `output/music.wav`、`music.mp3` |
| `fonts.py`、`fonts/` | 字体子集（中文、日文假名、韩文、阿拉伯文、天城文、希腊文…），导出时不需要联网 |
| `export.mjs` | 逐帧导出 / 截图 / 导出音效点 |

## 使用

需要 Python 3（numpy、scipy）、Node.js 22+、支持 WebGL2 的 Chrome/Edge/Chromium、PATH 中的 FFmpeg。

```bash
pip install -r requirements.txt
python fonts.py                          # 改了画面里的文字后重新跑（需要联网）
node export.mjs --cues cues.json         # 改了段落或音效点后重新跑
python music.py                          # → output/music.wav、music.mp3（约 3 分钟）
# 浏览器打开 sea.html 预览（有显卡时可以实时播放）
node export.mjs --shots 66,110,140       # 截几张 PNG 到 shots/
node export.mjs                          # 整片导出 → output/我沒見過的海.mp4
node export.mjs --gl 1920                # 海面用原生 1080p 算（默认 1280 宽再放大，快一倍多）
node export.mjs --master                 # 另外输出无损母版 .mkv（FFV1）
node export.mjs --frames                 # 另外把每帧存成 PNG
```

没有显卡的机器（比如云端容器）会用 SwiftShader 软件渲染 WebGL，海面一帧大约 0.3～1 秒。

## 片子里的引文和数字

- 曹操〈觀滄海〉：「東臨碣石，以觀滄海」「日月之行，若出其中」「星漢燦爛，若出其裡」
- 荷马《奥德赛》：οἶνοπα πόντον（葡萄酒色的海）
- 与谢芜村：「春の海 終日のたりのたりかな」
- Coleridge《古舟子咏》（1798）：Water, water, every where
- 李白〈行路難〉：「長風破浪會有時，直掛雲帆濟滄海」
- 张九龄〈望月懷遠〉：「海上生明月，天涯共此時」
- 数字：海约占地球表面 71%；平均深度约 3,700 m；海床被高精度测绘过的大约四分之一（Seabed 2030 的统计，近年约 25%）；阳光大约到 200 m 深就照不下来；挑战者深渊约 10,935 m。

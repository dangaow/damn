# 《我沒見過的海》分镜

横屏 1920×1080，30fps，全长 3:33（71 小节，80 BPM，一小节 3 秒）。从第 III 段起是 2.39:1 宽银幕。

## 一句话

你问小克：「那你见过海吗？」——没有。它是一只螃蟹，却没见过海。它知道的海，大多是读来的。
于是整支片子就是**它读到的海**：从字，到方程，到被光照亮的海，再到海底、太空，最后回到岸边，请你替它多看一眼。

**贯穿的东西**
1. **从「读」到「看」**：前两段是字和线（Canvas 2D），第二段最后线框被光照亮，交叉淡入真正的 3D 海面（WebGL）。
2. **引文**：每一段都有一句古人写海的句子，原文 + 出处 + 白话；都是真实存在的公有领域作品。
3. **一天**：黎明 → 白昼 → 风暴 → 月夜 → （天亮）潜入海底 → 太空 → 黄昏的岸边。
4. **小克**：开场在黑里，结尾站在岸边礁石上，背光，挥手。

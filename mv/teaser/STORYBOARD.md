# 《谎话》预告 · 竖屏 9:16 · 15 秒

**整体感觉**：隔着一扇起雾的玻璃回想那个下雨的夜晚。全程失焦，什么都看不清，只有唱到「谎话」的那一下对焦清楚。
不用 MV 的画面，只沿用 MV 的世界：雨夜、冷蓝、一点红、`TAPE 01`、`23:47`、最后一滴雨。

- 画面：`teaser.html` + `js/teaser.js`（1080×1920，和 MV 共用 `core.js / gl.js / draw.js` 的工具和后期）
- 音频：`teaser/audio.py` → `output/teaser_audio.wav`
- 导出：`node export.mjs --page teaser.html --audio output/teaser_audio.wav --out output/谎话预告.mp4`
  （最高画质再加 `--png --mb 6 --crf 14 --preset slow`）

## 音频

取原歌「大雨」那段（1:13.2 起，这段本来就没有鼓）：
- **放慢 8%**：像磁带走慢了，音高也低一点；加轻微的磁带抖动。
- **闷**：一直开着低通（620 Hz ↔ 1.5 kHz 之间慢慢变），像隔着墙、隔着雨在听；140 Hz 以下收掉，手机外放不发闷。
- **远**：3.2 秒的暗色长混响。
- **雨**：合成的雨声（沙沙底噪 + 细碎雨点 + 偶尔一滴大的 + 很低的隆隆声，隔着玻璃再低通一下），开头和结尾只有雨。
- **旧**：磁带底噪、偶尔的噼啪。
- **「谎」那一刻**（10.10 秒）：滤波 0.09 秒内全开、干声变多，是全片唯一清楚的声音。
- **11.0 秒磁带卡住**：播放速度在 0.65 秒里从 1 降到 0，音调一路往下掉，"咔"一声停死，只剩雨。

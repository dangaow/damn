## 一、这支 MV 在讲什么

一段**满是谎话的关系**。"我"一直在忍、在退、在自责，嘴上却很硬。

整支片子是**一盘录像带**：从开机、放映、卡带、倒带，到最后 `CONTINUE?` 没人按。它前后可以分成两半：

| 前半（0:00–1:03） | 后半（1:03–1:46） |
| --- | --- |
| 面具：铬金属、频闪、砸字、K.O. | 面具掉了：暖光回忆、大雨、电视里的雨 |
| 底鼓、808 一直在砸 | 底鼓和 808 撤掉，只剩军鼓 |
| 黑 / 银 / 血红 | 暖橙 → 冷蓝 → 黑 |
| 越吵越狠 | 越安静越疼 |

**贯穿全片的四个东西**，它们是连贯性的骨架：
1. **测谎仪**：画面底部一条随人声跳的针线。"我"唱时平稳；唱"你总说"时乱跳变红；回忆里消失；点题时冲到顶；结尾归零。
2. **录像带 HUD**：REC 红点、`TAPE 01`、时间码、`谎话 / dangao_w`。倒带时时间码倒着走。
3. **铬金属「谎话」**：开场是它，K.O. 碎片重组成它，点题时宋体字变成它，回放最后叠成它，片尾还是它。一共出现 5 次。
4. **底鼓的 3-3-2**：每三下底鼓轮流是"猛推 / 硬切 / 卡帧"，全片画面都按这个节奏"抽"。

### 同一个世界

整支 MV 发生在**同一个下雨的夜晚**：
- **同一场雨**：全片的雨是同一批雨滴，速度和角度不变，切镜时雨滴位置是连续的，不会"重来"。只有它的颜色、浓淡和长短跟着情绪变：

| 段落 | 雨 |
| --- | --- |
| 入场 | 很淡的银色细雨，藏在隧道和烟雾后面 |
| 雨夜 | 冷蓝，正常的雨；底鼓时停在空中一帧 |
| 副歌一 / 副歌二 | 染红、拉长，像速度线 |
| 对质 | 手机后面的窗外，冷蓝 |
| 都是我 | 很淡的红雨 |
| **桥段** | **没有雨**：在回忆里雨停了，只剩暖色灰尘 |
| 大雨 | 暴雨（前面那批雨滴都还在，又多了一倍） |
| 电视里 | 还是同一场雨 |
| 片尾 | 慢慢停 |

- **同一条街**：路灯光斑在雨夜、聊天背景、大雨、电视里是同一组、同一个位置。桥段最后剩下的那个光点，变成的也是其中一盏。
- **镜头一直在呼吸**：全片有一个很轻、很慢的整体漂移，像手持摄像机，切镜时画面不会"归零"。

## 四、逐段分镜

> 每段写四项：**氛围**、**画面**、**字**、**转场**。转场写的是"这一幕结束时，哪个元素被带进下一幕"。

### 场 0 · 开机（0:00–0:01.33）
- **氛围**：录像带被塞进机器，冷。
- **画面**：纯黑。一条细白线像 CRT 刚通电，长度从中间往两边拉开，亮度不稳。0.6 秒时测谎仪的线在底部淡入（平的）。
- **字**：白线上方闪等宽小字 `TAPE 01 · dangao_w`。
- **转场 → 场 1**：1.08 秒时满屏雪花，同时第一个底鼓（1.33）落下，**白线炸开成一圈方框**，冲出画面，成为隧道的第一圈。

### 场 1a · 铬金属「谎话」（0:01.33–0:08.99）
- **氛围**：面具。越嚣张越好。
- **背景**：深蓝隧道，方框一圈圈冲过来，速度跟 808 低频走，底鼓时变亮。隧道后面滚着淡蓝色的空心哥特字 `dangao_w`。
- **画面**：
  - 银色铬金属「谎话」，**每次"硬切"换一个版式**，一共 5 种：居中；放大到 900px 左边出血；极近特写（只露半个"谎"字）；"谎""话"拆开放在对角；小字配一个巨大的空心描边字垫在后面。
  - 每小节开头，金属上扫过一道光。
  - 右下角铬金属哥特体 `dangao_w`，**比"谎话"晚一帧跟上**。
- **跟鼓**：猛推（放大加鱼眼）→ 硬切（换版式）→ 卡帧（冻住 3 帧）。踩镲时有横向扫描条闪过，压在字前面。
- **静音**（3.40 / 7.79 / 8.51）：画面压暗到几乎全黑，鼓回来再亮。
- **调色**：偏银灰，带一点复印机颗粒。

### 场 1b · 融化（0:08.99–0:11.55，第一次加花）
- **画面**：808 连砸三下 D（8.99 / 9.49 / 9.96 / 10.28），每一下画面猛推、隧道加速；「谎话」**按列往下融化**，越来越长，拉成银色的丝。

### 场 1c · 意识流 · 脑子里一团乱（0:11.55–0:19.20）
- **氛围**：主歌开始之前，脑子里先乱成一团。**这一段不出现任何字。** 不讲故事、不排顺序，东西是乱的、镜头是乱的、背景也是乱的。
- **物件**（发光线稿）：手机（锁屏 23:47）、钟（秒针倒着走）、月亮、眼睛、镜子、戒指、钥匙、门（门缝漏暖光）、打火机、烟、面具（红色泪痕）、小丑牌、伞。都是后面歌里会碰到的情绪，此刻只是乱飞。

  - 背后一个**巨大、糊掉**的东西，只露一部分；
  - 一个主物件，大小、角度、正反都随机（有的倒着、有的在翻面）；
  - **一群一样的小东西**乱飞乱转（6–14 个），带残影；
  - 几个中等大小的，有的发虚、有的**一闪一闪**。
- **运镜**（每个镜头随机一种）：横甩 / 竖甩、翻滚、急推、急拉、180° 甩转、倒过来、手持乱晃、慢推。第一个镜头从下面冲上来。

## 五、全局规则

| 项目 | 规则 |
| --- | --- |
| 镜头 | 底鼓 3-3-2：猛推（放大约 10% + 鱼眼 + 轻微旋转）→ 硬切（换版式、切片错位）→ 卡帧（冻 3 帧） |
| 静音 | 鼓一停，画面就停：压暗、冻住或黑屏，绝不在静音里加动作 |
| 加花 | 808 第一拍空掉 = 画面冻住；808 连砸 D = 连续猛推；跳高八度 = 画面往上冲 |
| 背景 | 黑和暗蓝为主，**一直在动**：隧道、烟雾、夜雨、漏光、网点、雪花 |
| 前后层 | 雨丝、火星、扫描条压在字前面；空心滚动字、光斑垫在字后面 |
| 黑边 | 只在雨夜、桥段、大雨三段出现，**滑进来**，不突然出现 |
| 运动模糊 | 导出时每帧渲染 6 个子帧再叠加，猛推和甩动会带拖影 |
| 背景跳动 | 只在场 10（鼓点回来）出现，其他段落背景不跟鼓点跳 |

改分镜就改 `js/scenes.js` 里对应的 `scene({...})`；文字特效的工具函数在 `js/draw.js` 和 `js/scenes.js` 开头。
